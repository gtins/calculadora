# Calculadora Web

Projeto de uma calculadora simples desenvolvida com HTML, CSS e JavaScript. A aplicação é executada diretamente no navegador e realiza operações matemáticas básicas.

[Acesse a calculadora online](https://gtins.github.io/calculadora/)

---

## Funcionalidades

- Adição, subtração, multiplicação e divisão
- Interface amigável e responsiva
- Interações com botões e exibição em visor digital
- Lógica desenvolvida com JavaScript puro
